# Instruction stress test

This is a review of the instructions, not an executable or empirical test.

| Edge case | Required behaviour |
|---|---|
| AI replaces tasks; demand absorbs capacity | Report task replacement without automatically claiming displacement. |
| Employment grows below the no-AI path | Assess suppressed hiring with an explicit counterfactual. |
| Hours remain stable while expertise pay falls | Assess wage erosion separately. |
| Work shifts to contractors | Check workforce boundary before claiming less human work. |
| Different causes yield identical observations | Preserve unresolved attribution and identical assessments. |
| Comparator hides restructuring | Preserve false positives; test hidden confounding. |
| More seeds seem to confirm the hypothesis | Separate within-model randomness from structural validity. |
| Always abstaining avoids false alarms | Report coverage and misses alongside false alarms. |
| A theoretical objection stalls progress | Convert it to a test or record what is missing and continue. |
| Output adjustment removes AI demand effects | Distinguish total from conditional effects. |
| Work reaches publication or monitoring | Require explicit user instruction for that action. |

Checked against discovery: research plus implementation, separate outcomes, contestable hypothesis, experiments as priority, portfolio as first milestone, explicit collection/publication boundaries.
